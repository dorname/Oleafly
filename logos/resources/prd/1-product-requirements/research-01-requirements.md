# Oleafly 研究与文献 需求文档

> 最后更新：2026-11-09

## 一、产品背景与目标

### 1.1 产品定位（本模块范围内）

Oleafly 是本地优先（local-first）的研究写作工作区。research 模块覆盖写作之外的"研究与文献"半径：**文献检索与引用写入（Citation Search）→ Zotero 文献库集成 → 草稿文献发现与 AI 评审 → 图像/扫描件 OCR 转换 → 研究规划与本地统计工具**。本模块的权威数据源是项目本地的 BibTeX/Hayagriva 引用文件；检索结果、Zotero 条目、AI 评审与远程 OCR 都只是向它供给的外部来源。

### 1.2 核心目标

- 无网络时引用工作不中断：检索与 Zotero 云能力为显式操作，离线仍可继续使用本地 `.bib` 完成引用；
- 外部能力的数据去向透明：远程 OCR 运行前展示数据去向、页数与成本；AI 评审只发送短查询，不发送整个项目；
- 引用写入防重：多来源检索合并查重，Zotero 插入只追加该条目，外部元数据不得取代本地 `.bib` 的权威性。

### 1.3 目标用户画像

需要管理学术文献的研究者与研究生：以 DOI/arXiv/URL/标题等多来源检索文献；使用 Zotero 管理既有文献库；处理含扫描 PDF、公式截图的材料；需要会议截止日期与 p 值/样本量/置信区间等速算工具支持研究规划。

## 二、用户痛点分析（本模块相关）

### P05: 文献检索与引用整理碎片化
因为文献分散在 DOI、arXiv、网页与多个检索来源，BibTeX 条目靠手工誊写 → 导致条目格式混乱、重复条目与引用键错误 → 造成引用返工与投稿受阻。

### P06: Zotero 文献库与写作脱节
因为文献库（本机 Zotero 或 zotero.org）与写作编辑器分离 → 导致插引用要在两个工具间复制粘贴 → 造成条目不同步与重复劳动。

### P07: 草稿"该引而未引"发现靠人工
因为查找草稿遗漏的相关文献依赖人工回忆与翻检 → 导致关键引用缺失 → 造成审稿返修。

### P08: 扫描件与图像内容不可用
因为扫描 PDF、公式与图像中的内容无法直接转为可编辑文本 → 导致手工抄录 → 造成耗时与抄录错误。

### P09: 研究规划与统计速算工具分散
因为实验室检索、会议截止日期与 p 值/样本量/置信区间计算散落在网页和脚本中 → 导致频繁切换与重复查询 → 造成规划遗漏与统计误算。

## 四、核心场景详述

### S16: 文献检索与引用写入

- **触发条件**：写作中需要引用文献并维护项目的 BibTeX 文件。
- **用户价值**：多来源检索、合并查重、一键写入引用与 `.bib`，离线不中断（← P05）。
- **优先级**：P0
- **主路径**：按 DOI/arXiv/URL/标题进行单条或多来源检索 → 结果合并查重 → 插入引用到文稿并追加条目到 `.bib` → 引用 key 补全、校验与诊断。

#### 验收条件

##### 正常：多源检索与引用写入
- **GIVEN** 项目含本地 `.bib` 且检索来源可用
- **WHEN** 用户以 DOI/arXiv/URL/标题检索并插入引用
- **THEN** 引用插入文稿，对应条目追加至 `.bib`；多来源结果经合并查重去重；key 缺失时提供补全、校验与诊断

##### 异常：provider 不可用或无 Serper key
- **GIVEN** 某检索 provider 不可用，或未配置 Serper key
- **WHEN** 用户执行检索
- **THEN** provider 不可用被显式呈现，不静默吞掉；结果中不列 Google Scholar

##### 异常：无网络
- **GIVEN** 完全离线
- **WHEN** 用户需要插入引用
- **THEN** 仍可继续使用本地 `.bib` 完成引用写入

##### 边界：批量写入失败即停
- **GIVEN** 批量流程中 `.bib` 写失败
- **WHEN** 写入发生
- **THEN** 批量流程先停止，不静默跳过继续执行

##### 边界：参考文献文件导入（偏差 D4）

- UI 提供参考文献文件导入入口（EndNote XML / RIS / BibTeX，`FileReferencesDialog`）；基线原记为"实现支持、UI 入口待确认"，fix-doc-deviations 已确认 UI 入口存在并回补 docs/Citations.md（原 `inventory.md` 偏差 D4）

### S17: Zotero 文献库集成

- **触发条件**：用户已有本机 Zotero 7+（含 BBS）或 zotero.org 文献库。
- **用户价值**：写作中直接联合检索 Zotero 库，插入不重复、条目不被破坏（← P06）。
- **优先级**：P1
- **主路径**：连接本机 Zotero 7+/BBS 或 zotero.org → 在编辑器中 `@` 联合检索 → 插入时只追加该条目防止重复 → 缺失 key 批量补全 → 条目变更经审阅后更新。

#### 验收条件

##### 正常：联合检索与防重插入
- **GIVEN** 已连接本机 Zotero 7+/BBS 或 zotero.org
- **WHEN** 用户 `@` 检索并插入某条目
- **THEN** 仅追加该条目到项目引用文件，不重复导入；缺失 key 可批量补全；条目更新须经审阅后执行

##### 异常：Zotero 关闭或写失败
- **GIVEN** 本机 Zotero 未运行，或同步写失败/条目缺失 key
- **WHEN** 用户检索或同步
- **THEN** Zotero 关闭时使用缓存并明确标注；手改条目须确认才覆盖；任何条目不被自动删除；写失败与缺失 key 均明确报告

### S18: 草稿文献发现与 AI 评审

- **触发条件**：草稿成形后查漏补缺引用，或希望对相关工作获得评审反馈。
- **用户价值**：从文档出发发现应引文献并获分数与理由（← P07）。
- **优先级**：P2
- **主路径**：From document 扫描草稿 → 过滤已引用条目 → 查看分数与理由 → 加入书目；或使用 Review 获取流式反馈。

#### 验收条件

##### 正常：文档扫描发现
- **GIVEN** 已配置 AI 且网络可用
- **WHEN** 运行 From document 扫描
- **THEN** 结果过滤已引用条目并附分数与理由，可将条目加入书目；Review 提供流式反馈

##### 边界：降级与隐私
- 未配置 AI 时退化为启发式且不显示理由；离线禁用扫描；结果缓存约一天；只发送短查询，不发送整个项目

### S19: 图像与扫描件 OCR 转换

- **触发条件**：需要把图像、公式截图或扫描 PDF 转为可编辑文本。
- **用户价值**：OCR 本地优先（默认本机 Ollama），运行前数据去向、页数与成本透明（← P08）。
- **优先级**：P1
- **主路径**：选择 Image/Equation/PDF 扫描转换器 → 默认本机 Ollama 或显式选择远程模型 → 运行前查看数据去向、页数与成本 → 检查并保存结果。

#### 验收条件

##### 正常：本机 Ollama 转换
- **GIVEN** 本机 Ollama 可用
- **WHEN** 用户对图像/公式/扫描 PDF 运行转换
- **THEN** 运行前展示数据去向、页数与成本；结果可检查并保存

##### 异常：离线时远程转换被拒
- **GIVEN** 设备离线
- **WHEN** 尝试 hosted/Mathpix 等远程转换
- **THEN** 远程转换被拒绝，本机 Ollama 转换仍可用

##### 边界：页数与尺寸限制
- 扫描一次最多 50 页，超过 5 页需确认；托管图长边上限 2000px、CLI agent 图上限 760KB；只读 agent 仍可读取图

### S20: 研究规划与本地统计工具

- **触发条件**：研究规划（找实验室、盯会议截止）或统计速算。
- **用户价值**：在面板内完成查询、计算、复制与外链，非法输入可恢复（← P09）。
- **优先级**：P2
- **主路径**：使用 Lab Search / Conference Deadlines / p 值 / 样本量 / 置信区间工具 → 输入条件运行 → 查看、复制结果或跳转外链。

#### 验收条件

##### 正常：统计与规划工具
- **GIVEN** 用户打开统计或规划类工具
- **WHEN** 输入合法条件并运行
- **THEN** 在面板内查看结果，可复制或使用外链

##### 边界：数据范围与非法输入
- 会议截止数据以 CS 为主、非全学科；非法输入在面板内说明并恢复可运行状态；需要网络的工具在其自身面板声明

## 五、约束与边界

### 5.1 技术约束

- 引用的权威源是项目本地 BibTeX/Hayagriva 文件；检索结果与 Zotero 等外部元数据只作供给，不得取代其权威性（离线时本地 `.bib` 是唯一可用引用路径）。
- 网络能力（多源检索、zotero.org、AI 评审、hosted/Mathpix OCR）均为显式操作，且必须显式呈现失败；离线降级路径为本地 `.bib`、Zotero 缓存、启发式评审与本机 Ollama。
- OCR 类功能运行前必须透明呈现数据去向、页数与成本；AI 评审只发送短查询，不发送整个项目。
- 外部写入保持保守：`.bib` 批量写失败即停；Zotero 条目只追加、不自动删除、覆盖需确认。

### 5.2 现状声明（未验证项）

- 本基线为静态盘点：上文行为均有实现与测试证据（`citation.test.ts`、`zotero-cite.test.ts`、`zotero-actions.test.ts`、`DocumentCitationScanPanel.test.tsx`、`ad-hoc-converters.test.ts`、`StatsToolView.test.tsx` 等，证据行号见 `inventory.md`），但**本次未执行任何测试**；动态行为在 verify 阶段单独取证。

### 5.3 "不做"清单（本基线范围）

- 不新增任何功能或交互；只固化现状。
- 不在本模块内描述内置 Copilot/agent 等通用 AI 能力（分属 ai 模块）；S18/S19 仅记录其作为研究工具的现状边界。
- 不修复文档偏差本身（D4 等文档已由 fix-doc-deviations 对齐），基线一律以实现为准。
