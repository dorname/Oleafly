### S01: 从模板或外部资料创建研究项目

#### 功能入口与表面

- 入口：项目库的新建/导入流程（模板选择与导入来源输入）。
- 表面：模板选择（空白/内置/自定义模板）、导入来源选择（ZIP、DOCX、Markdown、HTML、Typst、目录）、确认前预览（引擎、文档类型、主文件、首页预览）。

#### 关键交互

1. 在项目库新建流程中选择空白/内置/自定义模板，或选择外部导入来源（ZIP / DOCX / Markdown / HTML / Typst / 目录）。
2. 查看确认页：引擎、文档类型、主文件与首页预览，用户确认后才继续。
3. 系统生成独立项目目录：导入内容复制进新项目，不改原文件；单根目录 ZIP 自动展开并推断主文档；导入项目强制关闭 shell escape，并初始化本地 Git。
4. 打开生成的项目主文件，继续编辑（衔接 S04）。

#### 能力与限制

- ZIP 导入上限：5000 entries / 2 GiB 解压总量 / 目录深度 16；超限或不可读时导入失败并明确报错，不留下半成品项目。
- 导入时跳过 `.git` / `.oleafly` / `__MACOSX` 与路径穿越条目。
- DOCX/Markdown/HTML/Typst 转换依赖 Pandoc；Pandoc 缺失时返回 `tools.pandoc_missing` 明确错误，不创建项目；转换失败保留输入，可重试。
- 删除模板不影响已创建的项目。
- 导入不改原件；arXiv 等外部来源失败时同样保留输入可重试。

#### 关联需求

- 场景：S01（从模板或外部资料创建研究项目）。
- 痛点：P01（工具链碎片化）。用户价值：一分钟内获得可编译、可继续写作的独立项目。
- 优先级：P0。

### S02: 从 arXiv 或 Git 仓库导入项目

#### 功能入口与表面

- 入口：arXiv ID / 本地 e-print 文件输入入口；Git 仓库 URL 输入入口。
- 表面：来源输入、下载/clone 进度、源文件预览与主 TeX 选择、commit 校验结果。

#### 关键交互

1. 用户输入 arXiv ID（经白名单校验后构造下载 URL）或提供本地 e-print，或输入 Git 仓库 URL。
2. 下载（arXiv tar.gz/gzip）或 clone（经 staging 区）后进行校验。
3. 预览源文件并选择主 TeX（arXiv 路径）；或校验 commit（Git 路径）。
4. 创建项目；Git 导入附加完整 history 与 origin，可继续转换为 Typst。

#### 能力与限制

- arXiv：仅白名单内 ID；e-print 解包上限 512 MiB / 5000 entries。
- e-print 只含 PDF 时明确提示"无 LaTeX source"，不静默当作成功；gzip/tar 损坏时报损坏错误。
- Git：空仓库、过大 tree/archive、非法 URL、认证失败均报对应错误；取消导入只停止该任务并清理进程树。
- staging 区在 24 小时后清理。
- 本节异常均不静默降级为成功。

#### 关联需求

- 场景：S02（从 arXiv 或 Git 仓库导入项目）。
- 痛点：P01（工具链碎片化）。用户价值：远程材料一键进入本地写作流。
- 优先级：P1。

### S03: 项目库检索与恢复

#### 功能入口与表面

- 入口：项目库检索输入框（全文词与限定词查询）。
- 表面：检索输入框、高级查询面板、项目卡片（元信息）、排序控件。

#### 关键交互

1. 在项目库输入全文词或 `is:` / `has:` / `engine:` / `kind:` / `created:` 限定词条件。
2. 使用 AND/OR、排除、日期范围与高级面板逐步收窄结果。
3. 按排序查看项目卡片元信息。
4. 打开目标项目恢复工作。

#### 能力与限制

- 未知限定词按普通文本处理并给出警告；不支持的值以琥珀色提示且被忽略；高级面板不能表达的查询显示 Custom。
- 引擎筛选支持 LaTeX / Typst / Markdown / Quarto / Calepin 五种（原偏差 D1，docs/ProjectLibrary.md 已对齐）。

#### 关联需求

- 场景：S03（项目库检索与恢复）。
- 痛点：P01（工具链碎片化）。用户价值：秒级定位项目并继续。
- 优先级：P1。

### S04: 多文件研究写作（源码/可视）

#### 功能入口与表面

- 入口：编辑器——文件树与 Code / Visual 两种撰写模式。
- 表面：文件树（增删改、主文档选择）、Code 编辑器（补全、结构视图、引用/标签检查、数学/图/表预览）、Visual 编辑模式、诊断呈现、项目级重命名。

#### 关键交互

1. 在文件树创建/重命名/复制文件，并指定主文档。
2. 以 Code 或 Visual 模式撰写：补全、结构视图、引用/标签检查、数学/图/表预览。
3. 所有修改写入普通源文件（无隐藏副本）。
4. 自动保存与诊断持续运行；项目级重命名后触发编译。

#### 能力与限制

- 自动保存触发时若仍有新编辑，dirty 状态保留并再次保存，不丢失输入。
- 旧 revision 的分析/诊断结果返回时被拒绝呈现，不误导当前编辑状态。
- `%novalidate` 仅关闭相应语法检查；编译错误、拼写、语法与引用检查仍继续。

#### 关联需求

- 场景：S04（多文件研究写作）。
- 痛点：P01（工具链碎片化）。用户价值：一个工作区内完成结构组织、撰写与项目级智能。
- 优先级：P0。

### S05: 本地拼写语法校对

#### 功能入口与表面

- 入口：应用/项目语言选择；编辑器内的校对发现呈现。
- 表面：语言选择、源位置上的发现与建议、忽略操作（项目/全局/会话三级）、规则与词典管理、设置中的计数复查。

#### 关键交互

1. 选择应用或项目语言。
2. 检查器以 prose mask 跳过命令、注释与数学，仅检查正文。
3. 在源位置查看发现与建议。
4. 按需忽略（项目/全局/会话范围）或调整规则与词典。
5. 在设置中复查校对计数。

#### 能力与限制

- 所选语言词典未安装时明确报告，不回退到其他语言。
- 非英语仅运行 Hunspell，grammar-only 请求返回 unsupported（原偏差 D5，docs/Editor.md 已对齐）。
- Harper 崩溃时重建检查器并标记结果为 partial。
- 英文场景：仅正文被检查，发现与建议定位到源位置。

#### 关联需求

- 场景：S05（本地拼写语法校对）。
- 痛点：P04（投稿规范核对繁琐）。用户价值：本地完成学术写作质量检查。
- 优先级：P1。

### S06: 图表绘制与插入

#### 功能入口与表面

- 入口：文档工具栏进入 Diagram Composer（继承文档语言），或独立入口选择语言。
- 表面：Diagram Composer 画布、Code 双向视图、编译预览（按行定位错误）、插入/保存选项、源文件内嵌模型注释。

#### 关键交互

1. 进入 Composer：继承当前文档语言（TikZ/Typst/Mermaid），或独立选择语言。
2. 画布与 Code 双向编辑，两侧内容保持一致。
3. 编译预览并按行定位错误，修正后重试。
4. 插入当前文档，或保存为 `figures/<name>.<ext>` / PNG / 新建图项目。
5. 后续通过源文件内嵌的模型注释重新打开画布再编辑。

#### 能力与限制

- Typst 图首次预览需要 fletcher 包；离线且未缓存时明确报告缺包，不假装修译成功。
- TikZ 含画布不理解的命令时，经画布编辑重写可能丢失该类命令——必须先有提示。
- Mermaid 代码手改后若未重新插入/保存 PNG，PDF 中显示代码而非新图。

#### 关联需求

- 场景：S06（图表绘制与插入）。
- 痛点：P01（工具链碎片化）。用户价值：图保持为代码，可再次编辑。
- 优先级：P1。

### S07: 编译引擎选择与工具链修复

#### 功能入口与表面

- 入口：编译入口中的引擎选择与编译设置。
- 表面：引擎选择（Tectonic / latexmk / Typst / Markdown(Pandoc)）、编译设置（持久化于 `project.json`）、规范化日志与源位置诊断、依赖安装/切换指引。

#### 关键交互

1. 选择编译引擎（Tectonic / latexmk / Typst / Markdown(Pandoc)），可移植设置写入 `project.json`。
2. 触发编译已保存源文件。
3. 查看规范化日志与源位置诊断，定位问题。
4. 接受带输出身份的 PDF（保留本地构建 provenance）。
5. 按明确提示安装/切换 TeX 发行版、TinyTeX、Typst 或依赖，修复工具链后重试。

#### 能力与限制

- latexmk 缺 TeX/latexmk/Biber 时启动前停止并给出具体修复指引，不伪装成一般编译失败。
- Tectonic 配置镜像不可用时改试上游并记录；离线且缺缓存文件时给出具体消息。
- shell escape 信任按目录+机器授予，不随 `project.json`、ZIP 或 Git 迁移到新位置，需重新授予。

#### 关联需求

- 场景：S07（编译引擎选择与工具链修复）。
- 痛点：P02（编译环境配置复杂）。用户价值：本地、可复现地编译，出问题时能自我修复。
- 优先级：P0。

### S08: 可复现代码文档（Quarto/Calepin）

#### 功能入口与表面

- 入口：打开 `.qmd` / `.Rmd` 文档或 Calepin 项目。
- 表面：代码执行风险提示与授权（按项目/机器）、输出格式选择（PDF/Typst/Beamer/HTML）、chunk/cell 错误与产物呈现。

#### 关键交互

1. 打开 `.qmd` / `.Rmd` 或 Calepin 项目。
2. 查看代码执行风险，并按项目/机器粒度明确授权。
3. 选择声明的输出格式，准备 Quarto/Calepin 与语言运行时。
4. 编译后查看 chunk/cell 错误与产物。

#### 能力与限制

- 未授权 Quarto 时使用 `--no-execute`；但含 filters、shortcodes、扩展或部分内联代码的项目必须拒绝编译直至授权，不得静默执行。
- Calepin 未授权且无已渲染结果时停止并说明；未授权只能渲染已存结果。
- Quarto 将覆盖非同源工作文件时停止并点名文件。
- `oleaflyc` 明确不支持构建 Quarto/Calepin 项目并如实显示。

#### 关联需求

- 场景：S08（可复现代码文档）。
- 痛点：P02（编译环境配置复杂）。用户价值：代码与文稿一体、结果可复现。
- 优先级：P1。

### S09: PDF 预览与源文核对演示

#### 功能入口与表面

- 入口：并排 PDF 预览或独立 PDF 窗口。
- 表面：PDF 预览（翻页、缩放、搜索、目录、旋转/反色）、SyncTeX/Tinymist 正反向跳转、演示模式（从头/当前页、演讲者信息）、下载当前 PDF。

#### 关键交互

1. 打开并排或独立 PDF 预览。
2. 翻页、缩放、搜索、目录、旋转/反色浏览。
3. 正反向定位：LaTeX 用 SyncTeX，Typst 0.13+ 用 Tinymist（源码↔PDF 双向跳转）。
4. 进入演示模式：从头/当前页开始演示，查看演讲者信息。
5. 下载当前 PDF。

#### 能力与限制

- 源码已变化时，旧 revision 的 PDF 结果被拒绝接受并显示 stale，不当作当前输出。
- 失败编译的 PDF 保留分两种情况（原偏差 D3，docs/PDFPreview.md 已对齐）：无新 PDF 时保留旧文件；有经指纹验证的 best-effort PDF 时显示新文件、保持 error 状态且不更新最后成功检查点。
- Typst 版本过旧或 Markdown 项目隐藏同步控件；选择 PDF 文本不触发跳转；加密 PDF 要求密码。

#### 关联需求

- 场景：S09（PDF 预览与源文核对演示）。
- 痛点：P01（工具链碎片化）。用户价值：所见即所得的双向核对。
- 优先级：P0。

### S10: 投稿前预检

#### 功能入口与表面

- 入口：预检运行入口（选择投稿 profile 与六类检查）。
- 表面：投稿 profile 选择（arXiv/IEEE/ACM/期刊/学位论文）、六类检查（编译/规范/可访问性/引用/隐私/ATS）、结果审阅视图（严重度、确定性、规则 ID、源/PDF 位置、标准条款）、可访问性导出准备。

#### 关键交互

1. 选择投稿 profile（arXiv/IEEE/ACM/期刊/学位论文）与六类检查，可独立或一起运行。
2. 预检读取源、编译日志与当前 PDF。
3. 按严重度、确定性、规则 ID、源/PDF 位置及标准条款审阅发现。
4. 修复问题，或在兼容时执行 LaTeX tagged preparation、Typst PDF/A 与 PDF/UA 导出。
5. 对 alt 文本质量、阅读顺序与对比度做人工/外部复核。

#### 能力与限制

- 所需输入缺失时结果标 partial，不得报告完全成功（如 source-only 模式且当前 PDF 缺失）。
- 不兼容 document class 拒绝 accessible preparation；未知 package 只给 caution。
- 106 条 PDF/UA 机器规则是子集：未读取的证据不计通过，不构成正式 conformance 声明。
- Markdown 项目不做源规则检查，但 PDF/ATS 等输出检查仍可运行。

#### 关联需求

- 场景：S10（投稿前预检）。
- 痛点：P04（投稿规范核对繁琐）。用户价值：机器可查项先清零，减少返稿。
- 优先级：P0。

### S11: 导出交付物

#### 功能入口与表面

- 入口：导出入口（格式由持久化引擎描述符声明）。
- 表面：导出格式选择（PDF/源码 ZIP/DOCX/HTML/Markdown/TXT/Typst/LaTeX/PPTX/EPUB/Typst 图片）、目标文件选择、警告与导出记录查看。

#### 关键交互

1. 按持久化引擎描述符选择目标格式（PDF / 源码 ZIP / DOCX / HTML / Markdown / TXT / Typst / LaTeX / PPTX / EPUB / Typst 图片等）。
2. 选择文件目标（绝对路径，父目录必须存在）。
3. 保存当前显示 PDF 或转换源文件。
4. 查看缺失内容/图/引用/数学警告与导出记录。
5. 对链接而非复制的媒体，随交付物一并携带。

#### 能力与限制

- 导出目标语义（实现现状，纠正文档 D2）：绝对路径且父目录必须存在；目标文件可以尚不存在。
- 目标格式转换失败时保留既有产物不破坏；PowerPoint 缺图直接失败且不保存。
- 导出 stale 或失败编译所得 PDF 时明确提醒。
- EPS 且不可转换时原样写入并警告。

#### 关联需求

- 场景：S11（导出交付物）。
- 痛点：P04（投稿规范核对繁琐）。用户价值：一次操作产出目标格式并保留警告记录。
- 优先级：P0。

### S12: 检查点恢复与加密迁移

#### 功能入口与表面

- 入口：Versioning 时间线。
- 表面：时间线（版本、引擎、主文档、文件列表、标签）、恢复操作、密码导出/导入加密历史、Keep latest / Reset 清理。

#### 关键交互

1. 成功编译且目录有变化时，后台自动生成独立检查点。
2. 在 Versioning 时间线查看版本、引擎、主文档与文件，并可加标签。
3. 选择某版本恢复（恢复之后新增的文件与 `.git`/`.oleafly` 保留），恢复后重新编译。
4. 用密码导出/导入完整加密历史，跨机迁移；或用 Keep latest / Reset 清理。

#### 能力与限制

- 部分文件无法完整捕获时不发布不完整快照，也不把成功编译改为失败；新编译取消旧捕获且不误报。
- 恢复本身是事务，中断回滚。
- 由更新版本 Oleafly 创建的加密 archive，旧版本导入时在改历史前拒绝；忘记密码不可恢复（明确边界）。
- 检查点存储与 Git 完全独立，互不替代。

#### 关联需求

- 场景：S12（检查点恢复与加密迁移）。
- 痛点：P03（版本安全与可恢复性差）。用户价值：每次成功编译都有可回退快照。
- 优先级：P0。

### S13: 本地 Git 版本管理与发布

#### 功能入口与表面

- 入口：Source Control 面板。
- 表面：diff / stage / discard 视图、commit 操作、remote 配置（GitHub/GitLab/Gitea/Forgejo/Codeberg/自建）、publish / push / pull 与 ahead/behind 状态。

#### 关键交互

1. 创建/导入项目时初始化 Git，形成 `Create project` 首提交基线。
2. 查看文件 diff，执行 stage / discard。
3. 仅在用户显式要求时 commit。
4. 配置 GitHub / GitLab / Gitea / Forgejo / Codeberg 或自建 remote。
5. 执行 publish、push、pull，并查看 ahead/behind。

#### 能力与限制

- 首提交内容超过 100 MiB、发现疑似 secret 或提交失败时：项目仍创建成功，不留下伪首提交，staged 内容被清理。
- Publish 排除疑似 secret 文件；历史中存在 secret 命名文件时必须 Cancel 或显式 Publish anyway（按文件名检查，Keynote `.key` 属已知误报边界）。
- 保存、编译、关闭项目均不自动产生 commit；只有用户显式 commit 才形成提交。
- 机器无 Git 时不影响项目使用，Source Control 面板转为安装指导。

#### 关联需求

- 场景：S13（本地 Git 版本管理与发布）。
- 痛点：P03（版本安全与可恢复性差）。用户价值：普通 Git 仓库，无锁定，可选发布。
- 优先级：P1。

### S14: 确定性格式转换

#### 功能入口与表面

- 入口：Settings → Experimentation 启用 LaTeX tools 后，从 Tools gallery / omnibar / slash command 选择转换器。
- 表面：Settings 的 Experimentation 开关、Tools gallery、omnibar、slash command、转换输入与结果查看。

#### 关键交互

1. 在 Settings → Experimentation 启用 LaTeX tools（gallery 默认关闭）。
2. 从 gallery / omnibar / slash command 选择转换器（LaTeX/Typst/Markdown/HTML/表格/公式/Mermaid 间迁移）。
3. 输入本地文件、CSV/TSV、HTML、公式或 Mermaid。
4. 用本地/已安装工具链执行确定性转换。
5. 检查输出，并复制、保存或打开为项目。

#### 能力与限制

- gallery 默认关闭，需先在 Experimentation 设置中启用。
- 标识检索服务不可用时，手工录入与本地格式化仍可用。
- 确定性 PDF 重建必须报告限制而非编造文本。
- 扫描件类输入不在本场景处理，走 S19（research 模块）。

#### 关联需求

- 场景：S14（确定性格式转换）。
- 痛点：P01（工具链碎片化）。用户价值：本地确定性转换，产物可检查。
- 优先级：P1。

### S15: 终端与命令面板

#### 功能入口与表面

- 入口：命令面板或文件树（在指定目录打开终端）；命令面板。
- 表面：终端面板（标签管理：重命名/着色，跨重开保留）、输出链接点击回跳、命令面板（编译、SyncTeX、导出、检查点、引用等调用入口）。

#### 关键交互

1. 从命令面板或文件树在指定目录打开终端。
2. 运行 shell / `oleafly` 命令。
3. 点击输出中的源位置/PDF/图片/URL，回到相应视图（终端相对路径仅匹配项目文件才成为链接）。
4. 重命名/着色终端标签（跨重开保留）。
5. 用命令面板调用编译、SyncTeX、导出、检查点、引用等功能。

#### 能力与限制

- 每项目最多 10 个 shell 标签。
- 关闭仍在运行程序的终端、切换项目或退出应用时需确认。
- 终端具备会话所有权校验与进程树 containment，但**不等于 Research Task 同级的 OS 沙箱**，不得错误宣传（实现边界）。

#### 关联需求

- 场景：S15（终端与命令面板）。
- 痛点：P01（工具链碎片化）。用户价值：不离开工作区完成高级操作。
- 优先级：P2。
