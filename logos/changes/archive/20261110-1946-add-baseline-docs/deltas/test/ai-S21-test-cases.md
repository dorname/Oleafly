## 一、单元测试用例

### 1.1 API 字段约束（来源：本期无适用来源）

本场景**无 HTTP API 端点与请求体字段约束可提取**：事实来源中的 API delta（`deltas/api/ai-01-mcp-cli-api.md`）只覆盖 MCP localhost 端点与 CLI JSON 契约（AI 执行路径④⑤），与本场景的**执行路径①内置 Copilot** 无交集（路径归属见需求 §1.2）；S21 的交互面是桌面内部 typed IPC 与前端审批卡，事实来源未给出 requestBody / parameters 明细。按基线口径**不得发明**字段约束，故本组**无适用 UT 条目**。

### 1.2 DB 约束（来源：本期无适用来源）

本场景**无 UNIQUE / CHECK 约束清单可提取**：事实来源未提供 ai 模块 DB DDL（`deltas/database/` 仅含 core 与 collab 两份）；S21 的 turn 快照由 Rust 侧 `agent_turns.rs` 承载，事实来源只给出行为与上限，未给出 UNIQUE / CHECK 明细。按基线口径**不得凭空发明**约束，故本组**无适用 UT 条目**。
