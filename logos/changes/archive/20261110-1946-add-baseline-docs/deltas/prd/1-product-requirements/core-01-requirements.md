# Oleafly 本地写作核心 需求文档

> 最后更新：2026-11-09

## 一、产品背景与目标

### 1.1 产品定位（本模块范围内）

Oleafly 是本地优先（local-first）的研究写作工作区。core 模块承载其最小完整闭环：**创建/打开项目 → 写作 → 引用由 research 模块供给 → 编译 → PDF 核对 → 预检 → 导出 → 恢复（检查点/Git）**。项目始终是普通文件目录（可被任意编辑器打开），不是专有数据库。

### 1.2 核心目标

- 用户不联网即可完成从建项目到导出投稿物的全部本地环节；
- 编译、预览、预检、检查点默认本地执行，网络能力全部为显式操作；
- 项目源文件（LaTeX/Typst/Markdown）是唯一权威数据源，任何功能不得产生隐藏副本。

### 1.3 目标用户画像

研究者与研究生：单人或小团队撰写 LaTeX/Typst/Markdown 论文、学位论文与报告；在本地电脑工作，重视数据自主与可复现；部分用户使用 Quarto/Calepin 可复现文档。

## 二、用户痛点分析（本模块相关）

### P01: 工具链碎片化
因为编辑器、编译器、PDF 阅读器、版本管理各自分离 → 导致写作中频繁切换工具、上下文丢失 → 造成效率低下与出错率上升。

### P02: 编译环境配置复杂
因为 TeX 发行版与依赖安装维护成本高 → 导致新人无法快速产出 PDF → 造成协作与投稿受阻。

### P03: 版本安全与可恢复性差
因为普通编辑器缺少面向"每次成功编译"的快照 → 导致误改难以回退 → 造成稿件损失风险。

### P04: 投稿规范核对繁琐
因为引用、图表、可访问性等问题靠人工排查 → 导致返稿与延误 → 造成研究产出节奏被打断。

## 四、核心场景详述

### S01: 从模板或外部资料创建研究项目

- **触发条件**：用户需要开始一份新文稿，或把既有材料（ZIP、DOCX、Markdown、HTML、Typst、文件夹）带入 Oleafly。
- **用户价值**：一分钟内获得可编译、可继续写作的独立项目（← P01）。
- **优先级**：P0
- **主路径**：在项目库选择空白/内置/自定义模板或导入来源 → 查看引擎、文档类型、主文件与首页预览并确认 → 生成的独立项目目录（导入不改原件）→ 打开源文件继续编辑。

#### 验收条件

##### 正常：模板创建
- **GIVEN** 用户在项目库新建流程中
- **WHEN** 选择一个模板并确认引擎、主文件与预览
- **THEN** 生成独立项目目录，打开后主文件可编辑，编译按声明引擎执行

##### 正常：ZIP/目录导入
- **GIVEN** 用户选择本地 ZIP 或目录导入
- **WHEN** 导入完成
- **THEN** 内容复制到新项目，原文件未被修改；单根目录 ZIP 自动展开，推断主文档；导入项目强制关闭 shell escape，本地 Git 初始化

##### 异常：ZIP 超限或不可读
- **GIVEN** ZIP 超过 5000 entries / 2 GiB 解压总量 / 深度 16，或不可读
- **WHEN** 用户尝试导入
- **THEN** 导入失败并明确报错，不留下半成品项目；跳过 `.git`/`.oleafly`/`__MACOSX` 与路径穿越条目

##### 异常：Pandoc 缺失
- **GIVEN** 用户导入 DOCX/Markdown/HTML/Typst 且 Pandoc 不可用
- **WHEN** 确认导入
- **THEN** 返回 `tools.pandoc_missing` 明确错误，不创建项目

### S02: 从 arXiv 或 Git 仓库导入项目

- **触发条件**：用户已有 arXiv 论文源或托管 Git 仓库。
- **用户价值**：远程材料一键进入本地写作流（← P01）。
- **优先级**：P1
- **主路径**：输入 arXiv ID（白名单校验后构造 URL）或 Git URL → 下载/clone 经 staging 校验 → 预览源文件选主 TeX / 校验 commit → 创建项目（Git 导入附加 history 与 origin）。

#### 验收条件

##### 正常：arXiv 导入
- **GIVEN** 用户提供有效 arXiv ID
- **WHEN** 导入完成
- **THEN** 源文件（tar.gz/gzip）解包为可编辑项目，可预览并选择主 TeX，可继续转换为 Typst

##### 异常：arXiv 只有 PDF 或损坏包
- **GIVEN** e-print 只含 PDF，或 gzip/tar 损坏
- **WHEN** 导入
- **THEN** 明确提示"无 LaTeX source"或损坏错误，不静默当作成功

##### 异常：Git 导入失败
- **GIVEN** 空仓库、过大 tree/archive、非法 URL 或认证失败
- **WHEN** 导入
- **THEN** 报对应错误；取消导入只停止该任务并清理进程树，staging 24 小时后清理

### S03: 项目库检索与恢复

- **触发条件**：用户返回既有工作，项目数量多。
- **用户价值**：秒级定位项目并继续（← P01）。
- **优先级**：P1
- **主路径**：输入全文词或 `is:/has:/engine:/kind:/created:` 条件 → 用 AND/OR、排除、日期范围与高级面板收窄 → 排序并查看卡片元信息 → 打开目标项目。

#### 验收条件

##### 正常：限定词检索
- **GIVEN** 项目库含多个不同引擎的项目
- **WHEN** 输入 `engine:typst is:pinned` 类组合条件
- **THEN** 结果正确过滤；引擎筛选支持 LaTeX/Typst/Markdown/Quarto/Calepin 五种（实现现状，文档待回补，见偏差 D1）

##### 异常：未知限定词或不支持的值
- **GIVEN** 输入含未知限定词或不接受的值
- **WHEN** 执行检索
- **THEN** 未知限定词按普通文本处理并给出警告；不支持的值以琥珀色提示且被忽略；高级面板不能表达的查询显示 Custom

### S04: 多文件研究写作（源码/可视）

- **触发条件**：日常撰写与组织多文件文稿。
- **用户价值**：在一个工作区内完成结构组织、撰写与项目级智能（← P01）。
- **优先级**：P0
- **主路径**：在文件树创建/重命名/复制文件并选主文档 → Code 或 Visual 模式撰写（补全、结构视图、引用/标签检查、数学/图/表预览）→ 写入普通源文件 → 自动保存、诊断、项目级重命名后触发编译。

#### 验收条件

##### 正常：多文件撰写与保存
- **GIVEN** 用户在多文件项目中
- **WHEN** 编辑多个文件并依赖自动保存
- **THEN** 所有修改写入普通源文件；自动保存触发时若仍有新编辑，dirty 状态保留并再次保存，不丢失输入

##### 正常：项目级重命名
- **GIVEN** 文件被其他文件引用
- **WHEN** 重命名或移动该文件
- **THEN** 项目内指向它的路径同步更新

##### 异常：过期分析结果
- **GIVEN** 项目状态已变化（旧 revision）
- **WHEN** 旧的分析/诊断结果返回
- **THEN** 被拒绝呈现，不误导当前编辑状态

##### 边界：%novalidate 语义
- **GIVEN** 源文件含 `%novalidate` 或区域标记
- **WHEN** 编辑器检查运行
- **THEN** 仅关闭相应语法检查；编译错误、拼写、语法与引用检查仍继续

### S05: 本地拼写语法校对

- **触发条件**：润色学术正文。
- **用户价值**：本地完成学术写作质量检查（← P04）。
- **优先级**：P1
- **主路径**：选择应用/项目语言 → 检查器以 prose mask 跳过命令、注释与数学 → 在源位置查看发现与建议 → 忽略（项目/全局/会话）或调整规则与词典 → 在设置中复查计数。

#### 验收条件

##### 正常：英文校对
- **GIVEN** 项目语言为英语且词典可用
- **WHEN** 编辑含命令与数学的正文
- **THEN** 仅正文被检查，命令/注释/数学被 mask；发现与建议定位到源位置

##### 异常：语言未安装
- **GIVEN** 所选语言词典未安装
- **WHEN** 校对运行
- **THEN** 明确报告该语言未安装，不回退到其他语言；非英语仅运行 Hunspell，grammar-only 返回 unsupported（实现现状，见偏差 D5）

### S06: 图表绘制与插入

- **触发条件**：需要为文稿绘制 TikZ/Typst/Mermaid 图。
- **用户价值**：图保持为代码，可再次编辑（← P01）。
- **优先级**：P1
- **主路径**：从文档工具栏进入并继承文档语言，或独立选择语言 → 画布与 Code 双向编辑 → 编译预览并按行定位错误 → 插入当前文档或保存 `figures/<name>.<ext>` / PNG / 新建图项目 → 通过源文件内嵌模型注释重新打开画布。

#### 验收条件

##### 正常：画布-代码双向编辑
- **GIVEN** 用户在 Diagram Composer 中
- **WHEN** 在画布绘制后切换到 Code（或反向）
- **THEN** 两侧内容一致；插入后文档获得对应语言源码

##### 异常：Typst 缺 fletcher
- **GIVEN** 离线且 fletcher 未缓存
- **WHEN** 首次预览 Typst 图
- **THEN** 明确报告缺包，不假装修译成功

##### 边界：画布表达力
- **GIVEN** TikZ 含画布不理解的命令
- **WHEN** 经画布编辑重写
- **THEN** 该类命令可能丢失——必须先有提示；Mermaid 代码手改后未重新插入/保存 PNG 时，PDF 显示代码而非新图

### S07: 编译引擎选择与工具链修复

- **触发条件**：需要产出 PDF。
- **用户价值**：本地、可复现地编译，出问题时能自我修复（← P02）。
- **优先级**：P0
- **主路径**：选择 Tectonic/latexmk/Typst/Markdown(Pandoc) 引擎，可移植设置写入 `project.json` → 编译已保存源 → 查看规范化日志与源位置诊断 → 接受带输出身份的 PDF（保留本地构建 provenance）→ 按明确提示安装/切换 TeX 发行版、TinyTeX、Typst 或依赖。

#### 验收条件

##### 正常：引擎编译
- **GIVEN** 项目声明引擎且工具链可用
- **WHEN** 触发编译
- **THEN** 产出 PDF、规范化日志与源位置诊断；编译设置持久化于 `project.json` 保证可复现

##### 异常：latexmk 依赖缺失
- **GIVEN** 选择 latexmk 但 TeX/latexmk/Biber 缺失
- **WHEN** 编译
- **THEN** 启动前停止并给出具体修复指引，不伪装成一般编译失败

##### 异常：Tectonic 镜像失败
- **GIVEN** 配置镜像不可用
- **WHEN** 编译需要下载包
- **THEN** 改试上游并记录；离线且缺缓存文件时给出具体消息

##### 边界：shell escape 信任
- **GIVEN** 项目在某目录/机器上被授予 shell escape 信任
- **WHEN** 项目经 `project.json`、ZIP 或 Git 迁移到新位置
- **THEN** 信任不随迁移，需在新位置重新授予

### S08: 可复现代码文档（Quarto/Calepin）

- **触发条件**：文稿含 R/Python/Julia 代码执行。
- **用户价值**：代码与文稿一体、结果可复现（← P02）。
- **优先级**：P1
- **主路径**：打开 `.qmd`/`.Rmd` 或 Calepin 项目 → 查看代码执行风险并按项目/机器明确授权 → 选择声明的输出（PDF/Typst/Beamer/HTML）并准备 Quarto/Calepin 与语言运行时 → 编译后查看 chunk/cell 错误与产物。

#### 验收条件

##### 正常：授权后执行
- **GIVEN** 用户已为项目/机器授权代码执行且运行时可用
- **WHEN** 编译
- **THEN** chunk/cell 按序执行，错误定位到具体 chunk，产物按所选输出生成

##### 异常：未授权 Quarto
- **GIVEN** 项目未授权代码执行
- **WHEN** 编译 Quarto
- **THEN** 使用 `--no-execute`；但含 filters、shortcodes、扩展或部分内联代码的项目必须拒绝编译直至授权，不得静默执行

##### 异常：Calepin 未授权且无已存结果
- **GIVEN** 未授权且无已渲染结果
- **WHEN** 编译
- **THEN** 停止并说明；Quarto 将覆盖非同源工作文件时停止并点名文件；`oleaflyc` 明确不支持构建这两类项目并如实显示

### S09: PDF 预览与源文核对演示

- **触发条件**：校对编译成果、汇报演示。
- **用户价值**：所见即所得的双向核对（← P01）。
- **优先级**：P0
- **主路径**：打开并排或独立 PDF → 翻页、缩放、搜索、目录、旋转/反色 → LaTeX 用 SyncTeX、Typst 0.13+ 用 Tinymist 正反向定位 → 从头/当前页演示并查看演讲者信息 → 下载当前 PDF。

#### 验收条件

##### 正常：双向跳转
- **GIVEN** LaTeX 项目编译成功（SyncTeX 可用）
- **WHEN** 在 PDF 点击某处 / 在源码某行触发反向
- **THEN** 分别跳转到对应源码行 / PDF 位置；Typst 0.13+ 经 Tinymist 等价支持

##### 异常：过期编译结果
- **GIVEN** 源码已变化，旧 revision 的 PDF 结果返回
- **WHEN** 预览请求该结果
- **THEN** 拒绝接受并显示 stale，不把旧结果当作当前输出

##### 边界：失败编译的 PDF 保留
- **GIVEN** 编译失败
- **WHEN** 预览刷新
- **THEN** 区分两种情况：无新 PDF 时保留旧文件；有经指纹验证的 best-effort PDF 时显示新文件、保持 error 状态且不更新最后成功检查点（实现现状，纠正文档过度简化，见偏差 D3）

##### 边界：引擎/文档限制
- Typst 过旧或 Markdown 项目隐藏同步控件；选择 PDF 文本不触发跳转；加密 PDF 要求密码

### S10: 投稿前预检

- **触发条件**：投稿或提交前质量把关。
- **用户价值**：机器可查项先清零，减少返稿（← P04）。
- **优先级**：P0
- **主路径**：选择投稿 profile（arXiv/IEEE/ACM/期刊/学位论文）与六类检查（编译/规范/可访问性/引用/隐私/ATS）独立或一起运行 → 读取源、编译日志与当前 PDF → 按严重度、确定性、规则 ID、源/PDF 位置及标准条款审阅 → 修复，或在兼容时执行 LaTeX tagged preparation、Typst PDF/A 与 PDF/UA 导出 → 对 alt 文本质量、阅读顺序与对比度做人工/外部复核。

#### 验收条件

##### 正常：完整预检
- **GIVEN** 源、日志与当前 PDF 均可用
- **WHEN** 运行所选检查
- **THEN** 发现按严重度与确定性分级呈现，含规则 ID 与源/PDF 位置

##### 异常：输入缺失
- **GIVEN** 所需输入缺失（如 source-only 模式且当前 PDF 缺失）
- **WHEN** 运行
- **THEN** 结果标 partial，不得报告完全成功；不兼容 document class 拒绝 accessible preparation，未知 package 只给 caution

##### 边界：能力声明
- 106 条 PDF/UA 机器规则是子集，未读取的证据不计通过，不构成正式 conformance 声明；Markdown 项目不做源规则检查，但 PDF/ATS 等输出检查仍可运行

### S11: 导出交付物

- **触发条件**：分享、投稿或归档。
- **用户价值**：一次操作产出目标格式并保留警告记录（← P04）。
- **优先级**：P0
- **主路径**：按持久化引擎描述符选择 PDF/源码 ZIP/DOCX/HTML/Markdown/TXT/Typst/LaTeX/PPTX/EPUB/Typst 图片等 → 选择文件目标 → 保存当前显示 PDF 或转换源 → 查看缺失内容/图/引用/数学警告与导出记录 → 对链接而非复制的媒体随交付物携带。

#### 验收条件

##### 正常：标准导出
- **GIVEN** 引擎描述符声明目标格式
- **WHEN** 导出到绝对路径目标
- **THEN** 产物落盘且目标文件可以尚不存在（父目录必须存在——实现语义，纠正文档 D2）；导出记录含警告

##### 异常：转换失败
- **GIVEN** 目标格式转换失败
- **WHEN** 导出
- **THEN** 保留既有产物不破坏；PowerPoint 缺图直接失败且不保存；导出 stale 或失败编译所得 PDF 时明确提醒

##### 边界：EPS
- **GIVEN** 交付物含 EPS 且不可转换
- **WHEN** 导出
- **THEN** EPS 原样写入并警告

### S12: 检查点恢复与加密迁移

- **触发条件**：误改需回退，或迁移到新机。
- **用户价值**：每次成功编译都有可回退快照（← P03）。
- **优先级**：P0
- **主路径**：成功编译且目录有变化时后台生成独立检查点 → 在 Versioning 时间线查看版本、引擎、主文档与文件并可加标签 → 恢复选定版本后重新编译 → 用密码导出/导入完整加密历史，或 Keep latest/Reset 清理。

#### 验收条件

##### 正常：检查点与恢复
- **GIVEN** 编译成功且项目文件有变化
- **WHEN** 稍后在时间线选择某版本恢复
- **THEN** 项目回到该版本且恢复之后新增的文件与 `.git`/`.oleafly` 保留；恢复本身是事务，中断回滚

##### 异常：不完整捕获
- **GIVEN** 部分文件无法完整捕获
- **WHEN** 检查点生成
- **THEN** 不发布不完整快照，也不把成功编译改为失败；新编译取消旧捕获且不误报

##### 异常：加密历史
- **GIVEN** 导出的加密 archive 由更新版本的 Oleafly 创建
- **WHEN** 旧版本导入
- **THEN** 在改历史前拒绝；忘记密码不可恢复（明确边界）

### S13: 本地 Git 版本管理与发布

- **触发条件**：需要正式版本历史或远程托管。
- **用户价值**：普通 Git 仓库，无锁定，可选发布（← P03）。
- **优先级**：P1
- **主路径**：创建/导入项目时初始化 Git 并形成 `Create project` 首提交 → 查看 diff、stage/discard → 仅在用户要求时 commit → 配置 GitHub/GitLab/Gitea/Forgejo/Codeberg 或自建 remote → publish、push、pull 并查看 ahead/behind。

#### 验收条件

##### 正常：本地工作流
- **GIVEN** 项目已初始化 Git
- **WHEN** 保存、编译、关闭项目
- **THEN** 均不自动产生 commit；只有用户显式 commit 才形成提交

##### 异常：首提交失败
- **GIVEN** 首提交内容超过 100 MiB、发现疑似 secret 或提交失败
- **WHEN** 创建项目
- **THEN** 项目仍创建成功，不留下伪首提交，staged 内容被清理

##### 异常：Publish 安全
- **GIVEN** Publish 检出疑似 secret 文件，或历史中存在 secret 命名文件
- **WHEN** 尝试发布
- **THEN** 排除疑似 secret；历史命中时必须 Cancel 或显式 Publish anyway（按文件名检查，Keynote `.key` 属已知误报边界）

##### 边界：Git 未安装
- **GIVEN** 机器无 Git
- **WHEN** 创建/打开项目
- **THEN** 不受影响，Source Control 面板转为安装指导

### S14: 确定性格式转换

- **触发条件**：在 LaTeX/Typst/Markdown/HTML/表格/公式/Mermaid 间迁移。
- **用户价值**：本地确定性转换，产物可检查（← P01）。
- **优先级**：P1
- **主路径**：在 Settings → Experimentation 启用 LaTeX tools → 从 gallery/omnibar/slash command 选择转换器 → 输入本地文件、CSV/TSV、HTML、公式或 Mermaid → 用本地/已安装工具链转换 → 检查并复制、保存或打开为项目。

#### 验收条件

##### 正常：确定性转换
- **GIVEN** 工具已启用且输入合法
- **WHEN** 执行转换
- **THEN** 输出可检查、可保存或建项目；同一输入产生确定输出

##### 异常：依赖不可用
- **GIVEN** 标识检索服务不可用
- **WHEN** 使用手工录入类工具
- **THEN** 手工录入与本地格式化仍可用；确定性 PDF 重建必须报告限制而非编造文本

### S15: 终端与命令面板

- **触发条件**：需要 shell、项目命令或快速操作入口。
- **用户价值**：不离开工作区完成高级操作（← P01）。
- **优先级**：P2
- **主路径**：从命令面板或文件树在指定目录打开终端 → 运行 shell/`oleafly` 命令 → 点击输出中的源位置/PDF/图片/URL 回到相应视图 → 重命名/着色标签（跨重开保留）→ 用命令面板调用编译、SyncTeX、导出、检查点、引用等。

#### 验收条件

##### 正常：终端与链接
- **GIVEN** 终端输出含匹配项目文件的路径
- **WHEN** 点击该路径
- **THEN** 在对应视图打开该位置；终端相对路径仅匹配项目文件才成为链接

##### 边界：生命周期与安全表述
- 每项目最多 10 个 shell 标签；关闭仍在运行程序的终端、切换项目或退出需确认
- 终端具备会话所有权校验与进程树 containment，但**不得宣传为与 Research Task 同级的 OS 沙箱**（实现边界）

## 五、约束与边界
